    If it does not connect
    

      
This needs Chrome or Edge — Firefox and Safari do not implement Web Serial.

      
Close anything else holding the port first. tio and this page cannot both
         read it: a serial port hands each byte to exactly one reader, so they would split the
         transfer between them and both get a corrupt fraction.

      
Pick the right interface. The badge presents several serial ports and only one is the
         console REPL - usually the lowest-numbered. If the page says nothing answered, come
         back and try the next one.

      
If the browser refuses because the page is not a secure context, serve it from
         localhost instead of opening the file directly:
         python3 -m http.server in this directory, then open
         http://localhost:8000/photo-grab.html.
